# Sena
Sobre o Projeto
O SENA é uma plataforma digital desenvolvida com o objetivo de transformar a experiência de busca por moradias e estadias temporárias. Inspirado em grandes plataformas de hospedagem, o projeto foca em um diferencial essencial: a segurança e a transparência na tomada de decisão do usuário.
Diferente de sistemas tradicionais que se limitam às características internas do imóvel, o SENA integra dados sobre o entorno urbano, oferecendo informações detalhadas sobre segurança, mobilidade, iluminação pública, acesso a serviços e qualidade de vida da região. A solução promove a participação colaborativa, permitindo que a comunidade compartilhe experiências e percepções, tornando o processo de escolha de um local para morar mais seguro, prático e consciente.

Tecnologias Utilizadas
O desenvolvimento da plataforma baseou-se em uma arquitetura robusta e centrada no usuário:
Front-end: HTML e CSS para uma interface intuitiva, acessível e responsiva. 
Back-end: Java, responsável pela lógica de negócio, autenticação e controle de acesso.  
Banco de Dados: SUPABASE para o armazenamento estruturado e seguro de dados. 

Funcionalidades Principais
Busca Inteligente: Pesquisa de imóveis com foco em localização e contexto urbano.  
Análise do Entorno: Visualização de pontos de interesse próximos, como delegacias e transporte público.  
Ambiente Colaborativo: Sistema de avaliações e comentários sobre bairros e moradias, incentivando a transparência.  
Segurança: Autenticação de usuários e controle de acesso para garantir a integridade da plataforma.
